# 업적 미션 설계

정리일: 2026-10-31. 기본 미션 6종의 이름·아이콘·아이콘 지급 기준과 반복 코인 보상 간격을 확정한다. 실제 달성 판정·보상 지급은 아직 구현하지 않았다. 미션 카드 디자인은 추후 수정한다.

## 확정한 기본 미션

| 미션 | 집계 대상 | 아이콘 지급 | 아이콘 파일 | 이후 보상 |
|---|---|---|---|---|
| 첫걸음 | 일반 문제 완료 개수 | 1개 | `leaf.svg` · 잎사귀 | 이 미션의 반복 보상은 없음. 일반 누적은 퍼즐 수집가에서 이어감 |
| 퍼즐 수집가 | 일반 문제 완료 개수 | 10개 | `puzzle.svg` · 퍼즐 조각 | 20·30·40개… 이후 10개마다 코인 |
| 꺼지지 않는 불 | 데일리 연속 수치 | 7 | `flame.svg` · 불꽃 | 14·21·28… 이후 7마다 코인 |
| 체리피커 | 난이도 하 일반 문제 완료 개수 | 10개 | `cherry.svg` · 체리 | 20·30·40개… 이후 10개마다 코인 |
| 두뇌 회전 | 난이도 중 일반 문제 완료 개수 | 10개 | `brain.svg` · 두뇌 | 20·30·40개… 이후 10개마다 코인 |
| 하드코어 | 난이도 상 일반 문제 완료 개수 | 10개 | `skull.svg` · 해골 | 20·30·40개… 이후 10개마다 코인 |

아이콘 파일은 `public/icons/achievement-preview/`에 있다. 아이콘은 각 미션의 지정된 최초 목표에서 한 번 지급한다. 같은 과제의 목표 숫자가 늘어나도 별도 미션이나 새 아이콘으로 나누지 않는다. 위 목표 이전의 1·3·5개 등에 별도 보상을 추가하지 않는다. 코인 보상량과 아이콘 지급 단계에서의 코인 동시 지급 여부는 별도로 정한다.

난이도 표기는 사이트의 하·중·상 표시와 같은 기준을 사용한다. 난이도별 미션은 일반 문제만 집계하며, 특수문제라도 난이도가 있으면 해당 난이도에 포함한다. 난이도 미지정 문제는 일반 누적에는 포함하되 난이도별 집계에는 포함하지 않는다.

꺼지지 않는 불은 데일리 누적 완료 횟수가 아닌 데일리 연속 수치를 기준으로 한다. 끊긴 기록의 재달성·소급 지급·중복 보상 처리와 현재/최장 기록의 저장 방식은 구현 전에 정리한다.

## 퍼스트 블러드: 보류

문제의 첫 완료자가 된 횟수를 세는 미션이다. 다음 사항은 확정하지 않았다.

- 일반 문제만 집계할지, 데일리 1등도 합산할지.
- 보상 단계와 아이콘 개수. 검 한 자루·교차한 검·왕관의 1·3·10회 구성은 비교용 후보다.
- 코인 보상 기준.

데일리 1등에게 타임머신 티켓을 주는 별도 보상 구상이 있으며, 티켓 수량과 지급 방식은 미정이다. 퍼스트 블러드 합산 여부를 결정한 것으로 취급하지 않는다.

## 별도로 구성할 미션

- 문제 묶음별 미션: 온도계 스도쿠, 수식완성, 사풍, 밸런스 루프, 빙판길, 침수된 길, 펜토미너스, 스타배틀 계열.
- 스타배틀은 기본 1·2, 침입자, 도미노, 배틀 스타, 스타 루프, 스타 디비전, 큐브를 한 묶음으로 구성한다. 이름·단계별 보상은 추후 확정한다.
- 특수문제 개별 미션: 한가위·란영·봄버스터즈·토마토스의 보상 구성을 별도로 정리한다.
- 전체 완료 특수 퀘스트: 해당 학기 일반 문제 전체 완료 시 별빛 반짝임을 지급한다. 자세한 내용은 [색상·효과 설계](achievement-badge-cosmetics-design.md)를 따른다.
