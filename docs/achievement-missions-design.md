# 업적 미션 설계

정리일: 2026-11-04. 기본 미션 6종의 이름·아이콘·아이콘 지급 기준과 반복 코인 보상 간격을 확정한다. 실제 달성 판정·보상 지급은 아직 구현하지 않았다. 미션 카드 디자인은 추후 수정한다.

## 데일리 과제

누적 업적과 별개로 매일 한 번씩 보상을 받는 과제다.

| 과제 | 달성 조건 | 보상 |
|---|---|---|
| 출석 체크 | 사이트 방문 | 20코인 |
| 하루 한 문제 | 일반 퍼즐 또는 데일리 스도쿠 1개 완료 | 100코인 |
| 데일리 챔피언 | 데일리 스도쿠를 1등으로 완료 | 타임머신 티켓 |

아이콘은 지급하지 않는다. 1등도 완료 과제 보상을 함께 받을 수 있다. 시안은 티켓을 1장으로 표시한다. 티켓 수량은 별도로 지정받지 않았으므로 1장은 시연 기준이다. 시안의 달성 기록은 가상이며 출석 체크만 완료 상태, 하루 한 문제와 데일리 챔피언은 미완료 상태로 보여준다. 과제 상단은 수령 전 0/1 또는 1/1, 수령 후 완료로 표시하고, 미완료 버튼은 진행 중으로 비활성화한다. 다른 사용자가 먼저 완료한 데일리 챔피언은 기회 종료로 표시하며 보상을 받을 수 없다. 시안은 이 기회 종료 상태를 보여준다. 수령 내역은 한국 날짜별로 분리하고 같은 날짜에는 중복 수령하지 않는다. 실제 판정·지급은 아직 연결하지 않았다.

## 확정한 기본 미션

| 미션 | 집계 대상 | 아이콘 지급 | 아이콘 파일 | 이후 보상 |
|---|---|---|---|---|
| 첫걸음 | 일반 문제 완료 개수 | 1개 | `leaf.svg` · 잎사귀 | 이 미션의 반복 보상은 없음. 일반 누적은 퍼즐 수집가에서 이어감 |
| 퍼즐 수집가 | 일반 문제 완료 개수 | 10개 | `puzzle.svg` · 퍼즐 조각 | 20·30·40개… 이후 10개마다 코인 |
| 꺼지지 않는 불 | 데일리 연속 수치 | 7 | `flame.svg` · 불꽃 | 14·21·28… 이후 7마다 코인 |
| 체리피커 | 난이도 하 일반 문제 완료 개수 | 10개 | `cherry.svg` · 체리 | 20·30·40개… 이후 10개마다 코인 |
| 두뇌 회전 | 난이도 중 일반 문제 완료 개수 | 10개 | `brain.svg` · 두뇌 | 20·30·40개… 이후 10개마다 코인 |
| 하드코어 | 난이도 상 일반 문제 완료 개수 | 10개 | `skull.svg` · 해골 | 20·30·40개… 이후 10개마다 코인 |

아이콘 파일은 `public/icons/achievement-preview/`에 있다. 아이콘은 각 미션의 지정된 최초 목표에서 한 번 지급한다. 같은 과제의 목표 숫자가 늘어나도 별도 미션이나 새 아이콘으로 나누지 않는다. 위 목표 이전의 1·3·5개 등에 별도 보상을 추가하지 않는다. 아이콘을 지급하는 단계에서는 코인을 함께 지급하지 않는다. 이후 코인 보상량은 별도로 정한다.

난이도 표기는 사이트의 하·중·상 표시와 같은 기준을 사용한다. 난이도별 미션은 일반 문제만 집계하며, 특수문제라도 난이도가 있으면 해당 난이도에 포함한다. 난이도 미지정 문제는 일반 누적에는 포함하되 난이도별 집계에는 포함하지 않는다.

꺼지지 않는 불은 화면에 표시되는 현재 데일리 연속 수치를 기준으로 한다. 누적 완료 횟수나 최장 연속 기록을 기준으로 하지 않는다. 끊긴 기록의 재달성·소급 지급·중복 보상 처리는 구현 전에 정리한다.

## 퍼스트 블러드: 일반 문제 1등 완료

공개된 일반 문제의 첫 완료자가 된 횟수를 세는 하나의 미션이다. 데일리 1등은 합산하지 않는다. 아래 단계별로 서로 다른 아이콘을 지급하며, 이전에 얻은 아이콘도 계속 선택할 수 있다.

| 일반 문제 1등 완료 횟수 | 보상 아이콘 | 파일 |
|---|---|---|
| 1회 | 검 한 자루 | `sword.svg` |
| 3회 | 교차한 검 | `swords.svg` |
| 10회 | 왕관 | `crown.svg` |

아이콘 파일은 `public/icons/achievement-preview/`에 있다. 아이콘 지급 단계에는 코인을 주지 않으며, 다른 단계의 코인 보상 기준은 미정이다. 데일리 1등 보상은 아래 데일리 과제로 별도 지급한다.

## 별도로 구성할 미션

- 문제 묶음별 미션은 공개된 문제가 3개 이상인 묶음만 구성하며, 해당 묶음의 문제를 3개 완료했을 때 아이콘을 지급한다. 2026-11-01 공개 목록 기준 대상은 스타배틀 계열 8개, 온도계 스도쿠 5개, 수식완성 3개, Spiral Galaxies 3개다. 미션 이름과 후속 보상은 추후 정한다.
- 스타배틀은 기본 1·2, 침입자, 도미노, 배틀 스타, 스타 루프, 스타 디비전, 큐브를 한 묶음으로 구성한다.
- Spiral Galaxies 미션의 보상 아이콘은 나선 은하(`public/icons/achievement-preview/galaxy.svg`)로 확정한다. 해당 종류의 공개 문제 3개를 완료하면 지급한다. 소용돌이·궤도·토성은 비교용 후보로만 남긴다.
- 사풍·밸런스 루프·빙판길·침수된 길·펜토미너스는 각각 공개 문제가 2개이므로 현재 묶음별 미션에서 제외한다. 추후 3개 이상이 되면 추가할 수 있다.
- 특수문제 개별 미션은 아래 확정 구성을 따른다.
- 전체 완료 특수 퀘스트: 해당 학기 일반 문제 전체 완료 시 별빛 반짝임을 지급한다. 자세한 내용은 [색상·효과 설계](achievement-badge-cosmetics-design.md)를 따른다.

## 특수문제 미션: 각 문제 1회 완료 보상

특수 미션은 각각 지정한 문제 하나를 완료하면 아이콘을 한 번 지급한다. 같은 종류의 여러 문제 완료를 요구하지 않고, 추가 단계·반복 코인 보상도 두지 않는다.

| 대상 문제 | 문제 ID | 보상 아이콘 | 사용 이미지 |
|---|---|---|---|
| 한가위 스도쿠 | `260925_01` | 토끼 | `/icons/seasonal/rabbit.svg` |
| 란영 스도쿠 | `260928_03` | 꽃 | `/icons/flower/flower.svg` |
| 봄버스터즈 스도쿠 | `261003_01` | 폭탄 | `/icons/bomb/bomb-red.svg` |
| 토마토스 스도쿠 | `261005_01` | 토마토 | `/icons/tomato.svg` |
| 주루마블 스도쿠 | `261101_03` | 잔 | `/icons/juru-marble/vodka-shot.png` |

퍼즐과 기존 배지에서 사용하는 이미지를 그대로 사용한다. 특히 주루마블은 Icons8 Vodka Shot 이미지를 사용하며 문자 이모지나 새 잔 아이콘으로 대체하지 않는다. 전체 완료로 별빛 반짝임을 주는 특수 퀘스트는 이 개별 문제 미션과 별개다.

특수 미션 보상은 아이콘의 모양만 지급하며 원본의 빨간 폭탄 등 고정 색상은 보상에 포함하지 않는다. 기본 표시는 무채색으로 통일하고, 색상은 별도의 색상 시스템으로 꾸민다. 퍼즐에서 사용하는 원본 이미지의 색은 변경하지 않는다.

## 확인용 페이지

- [마이페이지 v2](https://puzzle.xivnick.me/test/mypage-v2/): 계정에는 배지 없는 닉네임과 이메일만 둔다. 이름 옆 연필을 누르면 같은 자리에서 밑줄 입력칸과 작은 저장 버튼으로 전환하며 닉네임 라벨은 표시하지 않는다. 코인 잔액은 계정 섹션 오른쪽에 둔다. 현재 아이콘·아이콘 이름·색상 이름과 오른쪽 꾸미기 이동 링크도 계정 섹션 아래쪽에 함께 둔다. 별도 아이콘 섹션은 두지 않으며, 다음에 도전 과제를 표시한다. 마이페이지 섹션은 루트 문제 목록과 같은 제목·구분선·본문 여백을 사용하며, 도전 과제 분류는 제목 옆에 전체·일반·유형·특수만 둔다. 페이지 진입 시 보상 수령 가능→진행 중→완료 순으로 정렬하며 같은 상태에서는 기존 순서를 유지한다. 보상 수령이나 필터 변경으로 현재 행을 이동시키지 않고, 새로고침이나 재진입 시에만 저장된 수령 상태에 따라 다시 정렬한다. 계정·아이콘 요약·과제 행은 공통 행 여백과 좌우 들여쓰기를 사용하며 섹션 사이 간격도 공통값으로 관리한다. 수령 전후 행 여백은 같고, 수령 후 보상 줄만 숨긴다. 데일리·누적 과제의 보상 동작은 테두리 없는 밑줄 텍스트 버튼으로 표시한다. 꾸미기 페이지는 미리보기→꾸미기→뽑기→조합 순서로 구성한다. 코인 잔액은 뽑기 제목 오른쪽에 표시하며 기본으로 초기화하는 버튼은 두지 않는다. [꾸미기](https://puzzle.xivnick.me/test/mypage-v2/customize/)는 독립 페이지이며 미리보기를 첫 섹션으로 둔다. 꾸미기 섹션은 아이콘·색깔·효과의 현재 선택만 세 행으로 모은 통합 설정이다. 보유 항목을 미리 나열하는 줄은 없애고, 행을 누르면 선택 영역을 펼친다. 한 번에 한 행만 펼친다. 두 색 언커먼·레어를 고르면 색깔 선택 목록 바깥의 설정 행에서 표현·방향을 조정한다. 중복 색 이름은 표시하지 않는다. 조합은 뽑기 아래 독립 섹션으로 두며 재료 세 개를 선택해 실행한다. 뽑기는 꾸미기 아래의 독립 섹션으로 항상 표시하며 별도 화면 전환을 하지 않는다. 선택 후에도 펼친 상태를 유지해 비교할 수 있다. 일반적인 획득 안내 문장은 표시하지 않는다. 제목·구분선·본문 들여쓰기·섹션 간격은 마이페이지와 공통값을 쓴다. 선택한 아이콘·색깔·효과와 색 표현은 즉시 적용하고 보관한다. 별도 저장·취소 버튼 없이 제목 위 좌상단에 돌아가기 링크를 둔다. 아이콘 선택에는 보유한 아이콘만 표시하고 보유 표시와 전체 보유 수는 생략한다. 미보유 아이콘의 획득 조건은 도전 과제에서 확인한다. 효과도 보유한 항목만 표시하며 해제용 효과 없음 선택은 유지한다. 보유 효과가 없으면 효과 설정 행을 숨긴다. 기본·커먼 색깔에서는 효과 선택을 비활성화하고 언커먼 이상 필요로 표시한다. 뽑기 결과에는 꾸미기 이동 링크를 두지 않는다. 결과는 개별 밑줄 대신 간격을 둔 카드로 표시한다. 1회·10회 뽑기는 같은 결과 목록에 시간순으로 누적하며, 중복 결과도 각각 한 칸씩 남긴다. 뽑기 기록은 현재 페이지에 머무는 동안에만 유지하고, 재진입·새로고침하면 비운다. 획득한 아이템과 코인 잔액은 기록과 별개로 계속 보관한다. 코인 차감·획득 상태는 연출 전에 저장한다. 공개 연출 중에도 잔액이 충분하면 1회 뽑기를 반복할 수 있고 결과를 계속 추가한다. 각 연출을 독립적으로 관리한다. 결과는 자동으로 공개하며 모두 보기 버튼은 두지 않는다. 10회 뽑기와 조합은 공개 중 비활성화한다. 약 0.6초 후부터 결과를 순차 공개한다. 동작 줄이기 설정이나 페이지가 숨겨진 경우 즉시 결과를 보여준다. 시연 설명은 표시하지 않는다. 뽑기 버튼과 같은 구역 안에 짧은 획득 설명과 접어서 여는 확률표를 둔다. 뽑기 설명은 “아이콘을 꾸밀 색깔과 효과를 뽑아보세요.” 한 문장으로 표시한다. 뽑기 등급 확률은 커먼 72%·레어 24%·에픽 4%로 확정한다. 확률표와 무작위 추첨은 동일한 데이터의 확률을 사용하고 등급 내 항목은 균등하게 추첨한다. 가상 닉네임·코인·보상·꾸미기는 같은 탭의 sessionStorage에 보관해 페이지 이동과 새로고침에도 유지하며, 시안 초기화 버튼으로 지운다. 실제 계정에는 연결하지 않는다. 누적 과제 코인 보상량·뽑기 가격은 미확정 예시다. 데일리 출석 20코인과 완료 100코인은 확정값이다. 서로 다른 재료 세 종류는 시연 편의상 앞의 두 색을 사용하며, 정식 조합 규칙은 미확정이다.

- [전체 미션 정리](https://puzzle.xivnick.me/test/achievement-badges/mission-overview/): 기본 6개·퍼스트 블러드 1개·문제 묶음 4개·특수문제 5개·전체 완료 1개를 모은 종합 예시. 이름·후속 보상 등 미정 항목은 별도로 표시한다. 공개 문제 목록 스냅샷은 `src/data/achievement-missions-preview.json`에 있다.

- [Spiral Galaxies 아이콘 비교](https://puzzle.xivnick.me/test/achievement-badges/galaxy-icons/): 나선 은하를 보상 아이콘으로 확정.
- [특수 미션 5종](https://puzzle.xivnick.me/test/achievement-badges/special-missions/): 각 지정 문제 완료 시 해당 아이콘 1회 지급.
- [첫걸음·퍼즐 수집가·꺼지지 않는 불](https://puzzle.xivnick.me/test/achievement-badges/basic-missions/): 이름과 아이콘 확정. 카드 디자인은 최종안이 아니다.
- [난이도별 미션 3종](https://puzzle.xivnick.me/test/achievement-badges/difficulty-missions/): 이름과 아이콘 확정. 카드 디자인은 추후 수정한다.
- [퍼스트 블러드 아이콘](https://puzzle.xivnick.me/test/achievement-badges/first-blood-icons/): 일반 문제 1등 완료 1·3·10회에 검·교차한 검·왕관 지급으로 확정.

색상·효과와 닉네임 옆 공통 정렬 방식은 [업적 배지 색상·효과 설계](achievement-badge-cosmetics-design.md)를 따른다.

- [꾸미기 배치 5안 비교](https://puzzle.xivnick.me/test/customize-layouts/): 두 줄 미리보기·선택 항목만·항상 펼친 바둑판·가로 목록·통합 설정 목록. 같은 보유 항목과 공통 미리보기로 비교하며, 각 안에서 독립적으로 선택한다. 실제 계정과 기존 시안의 저장 상태는 바꾸지 않는다.

## 조합과 중복 보상

조합은 커먼 색깔 3개로 언커먼을 만드는 경로만 남긴다. “커먼 색깔 3개를 조합해 언커먼 색깔을 만드세요.”라는 설명을 표시한다. 재료 목록은 접어두며, 빈 재료 칸을 누르면 보유 커먼 색깔 전체를 보여준다. 목록은 고를 때마다 닫지 않고 세 개를 연달아 선택하게 한다. 같은 재료는 보유 수량만큼 반복해서 넣을 수 있다. 선택한 칸을 누르면 해당 재료를 뺀다. 목록 제목·선택 개수·선택 비우기는 표시하지 않고 닫기만 둔다. 세 개를 고르면 목록을 자동으로 접는다. 펼침과 접힘은 높이·투명도를 함께 전환하고, 접힌 영역은 포커스와 접근성 탐색에서 제외한다. 동작 줄이기 설정에서는 즉시 전환한다. 조합 영역 아래에 조합 결과를 카드로 누적하고 중복 코인 지급도 표시한다. 언커먼·레어 3개와 중복 에픽을 사용하는 레어 이상 뽑기는 제거한다.

| 중복 항목 | 처리 |
|---|---|
| 커먼 | 수량 누적, 조합 재료로 사용 |
| 언커먼 | 기존 색깔 1개를 유지하고 100코인 지급 |
| 레어 | 기존 색깔 1개를 유지하고 100코인 지급 |
| 에픽 | 기존 효과 1개를 유지하고 500코인 지급 |

언커먼 중복은 조합 결과를 지급할 때 판정하고, 레어·에픽은 뽑기 결과를 하나씩 지급하면서 판정한다. 한 번에 10개를 뽑아 같은 신규 항목이 두 번 나오면 첫 번째만 신규이고 두 번째부터 중복이다. 결과 카드에 중복 및 지급 코인을 표시한다. 별도 뽑기권은 추가하지 않는다. 이전 시안에 저장된 언커먼·레어·에픽 초과 수량은 같은 기준으로 한 번 코인 정산하고 최초 보유분을 유지한다.
