# 업적 미션 설계

정리일: 2026-11-02. 기본 미션 6종의 이름·아이콘·아이콘 지급 기준과 반복 코인 보상 간격을 확정한다. 실제 달성 판정·보상 지급은 아직 구현하지 않았다. 미션 카드 디자인은 추후 수정한다.

## 확정한 기본 미션

| 미션 | 집계 대상 | 아이콘 지급 | 아이콘 파일 | 이후 보상 |
|---|---|---|---|---|
| 첫걸음 | 일반 문제 완료 개수 | 1개 | `leaf.svg` · 잎사귀 | 이 미션의 반복 보상은 없음. 일반 누적은 퍼즐 수집가에서 이어감 |
| 퍼즐 수집가 | 일반 문제 완료 개수 | 10개 | `puzzle.svg` · 퍼즐 조각 | 20·30·40개… 이후 10개마다 코인 |
| 꺼지지 않는 불 | 데일리 연속 수치 | 7 | `flame.svg` · 불꽃 | 14·21·28… 이후 7마다 코인 |
| 체리피커 | 난이도 하 일반 문제 완료 개수 | 10개 | `cherry.svg` · 체리 | 20·30·40개… 이후 10개마다 코인 |
| 두뇌 회전 | 난이도 중 일반 문제 완료 개수 | 10개 | `brain.svg` · 두뇌 | 20·30·40개… 이후 10개마다 코인 |
| 하드코어 | 난이도 상 일반 문제 완료 개수 | 10개 | `skull.svg` · 해골 | 20·30·40개… 이후 10개마다 코인 |

아이콘 파일은 `public/icons/achievement-preview/`에 있다. 아이콘은 각 미션의 지정된 최초 목표에서 한 번 지급한다. 같은 과제의 목표 숫자가 늘어나도 별도 미션이나 새 아이콘으로 나누지 않는다. 위 목표 이전의 1·3·5개 등에 별도 보상을 추가하지 않는다. 아이콘을 지급하는 단계에서는 코인을 함께 지급하지 않는다. 이후 코인 보상량은 별도로 정한다.

난이도 표기는 사이트의 하·중·상 표시와 같은 기준을 사용한다. 난이도별 미션은 일반 문제만 집계하며, 특수문제라도 난이도가 있으면 해당 난이도에 포함한다. 난이도 미지정 문제는 일반 누적에는 포함하되 난이도별 집계에는 포함하지 않는다.

꺼지지 않는 불은 화면에 표시되는 현재 데일리 연속 수치를 기준으로 한다. 누적 완료 횟수나 최장 연속 기록을 기준으로 하지 않는다. 끊긴 기록의 재달성·소급 지급·중복 보상 처리는 구현 전에 정리한다.

## 퍼스트 블러드: 일반 문제 1등 완료

공개된 일반 문제의 첫 완료자가 된 횟수를 세는 하나의 미션이다. 데일리 1등은 합산하지 않는다. 아래 단계별로 서로 다른 아이콘을 지급하며, 이전에 얻은 아이콘도 계속 선택할 수 있다.

| 일반 문제 1등 완료 횟수 | 보상 아이콘 | 파일 |
|---|---|---|
| 1회 | 검 한 자루 | `sword.svg` |
| 3회 | 교차한 검 | `swords.svg` |
| 10회 | 왕관 | `crown.svg` |

아이콘 파일은 `public/icons/achievement-preview/`에 있다. 아이콘 지급 단계에는 코인을 주지 않으며, 다른 단계의 코인 보상 기준은 미정이다. 데일리 1등에게 타임머신 티켓을 주는 별도 보상 구상은 유지하며, 티켓 수량과 지급 방식은 미정이다.

## 별도로 구성할 미션

- 문제 묶음별 미션은 공개된 문제가 3개 이상인 묶음만 구성하며, 해당 묶음의 문제를 3개 완료했을 때 아이콘을 지급한다. 2026-11-01 공개 목록 기준 대상은 스타배틀 계열 8개, 온도계 스도쿠 5개, 수식완성 3개, Spiral Galaxies 3개다. 미션 이름과 후속 보상은 추후 정한다.
- 스타배틀은 기본 1·2, 침입자, 도미노, 배틀 스타, 스타 루프, 스타 디비전, 큐브를 한 묶음으로 구성한다.
- Spiral Galaxies 미션의 보상 아이콘은 나선 은하(`public/icons/achievement-preview/galaxy.svg`)로 확정한다. 해당 종류의 공개 문제 3개를 완료하면 지급한다. 소용돌이·궤도·토성은 비교용 후보로만 남긴다.
- 사풍·밸런스 루프·빙판길·침수된 길·펜토미너스는 각각 공개 문제가 2개이므로 현재 묶음별 미션에서 제외한다. 추후 3개 이상이 되면 추가할 수 있다.
- 특수문제 개별 미션은 아래 확정 구성을 따른다.
- 전체 완료 특수 퀘스트: 해당 학기 일반 문제 전체 완료 시 별빛 반짝임을 지급한다. 자세한 내용은 [색상·효과 설계](achievement-badge-cosmetics-design.md)를 따른다.

## 특수문제 미션: 각 문제 1회 완료 보상

특수 미션은 각각 지정한 문제 하나를 완료하면 아이콘을 한 번 지급한다. 같은 종류의 여러 문제 완료를 요구하지 않고, 추가 단계·반복 코인 보상도 두지 않는다.

| 대상 문제 | 문제 ID | 보상 아이콘 | 사용 이미지 |
|---|---|---|---|
| 한가위 스도쿠 | `260925_01` | 토끼 | `/icons/seasonal/rabbit.svg` |
| 란영 스도쿠 | `260928_03` | 꽃 | `/icons/flower/flower.svg` |
| 봄버스터즈 스도쿠 | `261003_01` | 폭탄 | `/icons/bomb/bomb-red.svg` |
| 토마토스 스도쿠 | `261005_01` | 토마토 | `/icons/tomato.svg` |
| 주루마블 스도쿠 | `261101_03` | 잔 | `/icons/juru-marble/vodka-shot.png` |

퍼즐과 기존 배지에서 사용하는 이미지를 그대로 사용한다. 특히 주루마블은 Icons8 Vodka Shot 이미지를 사용하며 문자 이모지나 새 잔 아이콘으로 대체하지 않는다. 전체 완료로 별빛 반짝임을 주는 특수 퀘스트는 이 개별 문제 미션과 별개다.

특수 미션 보상은 아이콘의 모양만 지급하며 원본의 빨간 폭탄 등 고정 색상은 보상에 포함하지 않는다. 기본 표시는 무채색으로 통일하고, 색상은 별도의 색상 시스템으로 꾸민다. 퍼즐에서 사용하는 원본 이미지의 색은 변경하지 않는다.

## 확인용 페이지

- [마이페이지 v2](https://puzzle.xivnick.me/test/mypage-v2/): 상단 왼쪽에 닉네임 배지와 연필 모양 계정 설정 버튼, 오른쪽에 코인 잔액과 뽑기 버튼을 둔다. 계정 설정에서 닉네임·아이콘·색상·효과를 함께 변경하고 한 번에 저장한다. 기본 화면은 도전 과제 목록이며, 계정 이메일은 시안용 주소를 표시한다. 계정 설정·뽑기는 팝업 없이 각각 별도 보기로 열며 같은 버튼을 다시 누르면 닫힌다. 색 조합은 색상 화면 안에서 펼치고 접는다. 닉네임 변경은 시안 내에서만 반영하며 실제 계정에는 반영하지 않는다. 별도 뒤로 버튼은 두지 않는다. 아이콘 설정 하단에는 취소와 저장 버튼을 고정하며 저장 후 도전 과제로 돌아온다. 저장 없이 나가면 마지막 적용 상태를 유지한다. 미션 보상 받기, 1회·10회 뽑기, 아이콘·색상·효과 선택, 커먼 3개 조합과 대표 배지 적용을 가상 데이터로 시연한다. 계정과 연결하지 않으며 새로고침하면 초기화한다. 코인 보상량·뽑기 가격·결과 구성은 미확정 예시다. 세 종류의 서로 다른 재료를 조합할 때에는 시연 편의상 앞의 두 색을 사용하며, 정식 조합 규칙을 확정한 뜻은 아니다.

- [전체 미션 정리](https://puzzle.xivnick.me/test/achievement-badges/mission-overview/): 기본 6개·퍼스트 블러드 1개·문제 묶음 4개·특수문제 5개·전체 완료 1개를 모은 종합 예시. 이름·후속 보상 등 미정 항목은 별도로 표시한다. 공개 문제 목록 스냅샷은 `src/data/achievement-missions-preview.json`에 있다.

- [Spiral Galaxies 아이콘 비교](https://puzzle.xivnick.me/test/achievement-badges/galaxy-icons/): 나선 은하를 보상 아이콘으로 확정.
- [특수 미션 5종](https://puzzle.xivnick.me/test/achievement-badges/special-missions/): 각 지정 문제 완료 시 해당 아이콘 1회 지급.
- [첫걸음·퍼즐 수집가·꺼지지 않는 불](https://puzzle.xivnick.me/test/achievement-badges/basic-missions/): 이름과 아이콘 확정. 카드 디자인은 최종안이 아니다.
- [난이도별 미션 3종](https://puzzle.xivnick.me/test/achievement-badges/difficulty-missions/): 이름과 아이콘 확정. 카드 디자인은 추후 수정한다.
- [퍼스트 블러드 아이콘](https://puzzle.xivnick.me/test/achievement-badges/first-blood-icons/): 일반 문제 1등 완료 1·3·10회에 검·교차한 검·왕관 지급으로 확정.

색상·효과와 닉네임 옆 공통 정렬 방식은 [업적 배지 색상·효과 설계](achievement-badge-cosmetics-design.md)를 따른다.
