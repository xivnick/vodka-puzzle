# 업적 보상 균형 검토

뽑기 가격은 1회 100코인으로 확정한다. 운영 DB의 draft 가격과 반복 보상을 반영했으며 기능은 비활성 상태다. 데일리 챔피언은 티켓 1장이다. 일반 문제 도전과제는 출시 전 기록도 포함하며 일일 과제는 출시일부터 시작한다.

## 뽑기 수집 속도

커먼 색깔 36종, 레어 색깔 24종, 에픽 효과 5종으로 총 65종이다. 확률은 72%·24%·4%이며 등급 안에서는 균등하다. 아이템별 1회 확률은 커먼 2%, 레어 1%, 에픽 0.8%다.

시작 보유가 없고 조합을 하지 않을 때, 서로 다른 33종을 얻는 시점을 전체 절반 달성으로 정의한다. 기본 색·미션 아이콘·조합 전용 언커먼·별빛 반짝임은 뽑기 수집 대상에서 제외한다. 획득 횟수가 아닌 서로 다른 종류 수를 센다.

| 지표 | 결과 |
|---|---:|
| 평균 뽑기 횟수 | 47.535회 |
| 중앙값 | 47회 |
| 10%가 달성하는 시점 | 41회 |
| 90%가 달성하는 시점 | 54회 |
| 95%가 달성하는 시점 | 57회 |
| 평균 총 뽑기 지출 | 4,753.5코인 |
| 평균 중복 환급 | 380.3코인 |
| 평균 순지출 | 4,373.2코인 |

레어 중복 100코인, 에픽 중복 500코인 환급을 반영한다. 커먼은 수량으로 쌓이며 환급이 없다. 초기 코인·업적 보상·조합·추가 지급은 포함하지 않는다. 순지출은 종료 시점까지 지출에서 환급을 뺀 값이며, 중간에 필요한 잔액이나 완료까지 걸리는 실제 일수와 같지 않다.

출석 20코인과 하루 한 문제 100코인을 매일 받으면 일일 120코인이다. 평균 순지출은 이 보상의 약 36.4일치에 해당한다. 실제 달성 일수는 수령·뽑기 시점과 중복 환급에 따라 달라지며 이번에 확정한 반복 업적 보상을 받으면 더 빨라진다. 위 순지출 계산에는 반복 보상을 포함하지 않았다.

전체 절반에 도달한 시점의 평균 보유 종류 수는 커먼 22.26종, 레어 9.15종, 에픽 1.59종이다. 전체 절반이 등급별 절반을 뜻하지는 않는다.

| 독립적인 수집 목표 | 평균 전체 뽑기 횟수 |
|---|---:|
| 커먼 18/36종 | 33.97회 |
| 레어 12/24종 | 67.27회 |
| 에픽 3/5종 | 97.92회 |

각 행은 해당 목표만 달성할 때까지의 평균이며 세 행을 더하지 않는다. 세 등급의 절반을 모두 얻는 시점은 별도의 목표다.

## 계산 방법

`node scripts/analyze-cosmetic-collection.mjs`로 재계산한다. 상태를 등급별 고유 보유 수 `(c,r,e)`로 두고 새 종류·중복 확률을 계산하는 동적 계획법이다. 무작위 시뮬레이션의 표본 평균이 아니다. 독립적인 전방 확률 분포의 생존 확률 합과 평균 대기 시간이 일치하는지도 검사한다.

스크립트의 확률·가격·중복 환급은 이번 확정값으로 명시되어 있으며, 운영 설정을 자동으로 수정하지 않는다. 종류 수는 현재 시안 목록에서 읽는다.

## 확정한 반복 보상

| 미션 | 반복 보상 |
|---|---|
| 퍼즐 수집가 | 20개부터 10개마다 100코인 |
| 체리피커 / 두뇌 회전 / 하드코어 | 20개부터 10개마다 30 / 60 / 90코인 |
| 꺼지지 않는 불 | 7 아이콘, 30부터 30마다 타임머신 티켓 1장 |
| 행운을 빌어요 | 10회부터 5회마다 10~100코인, 10단위 균등 무작위 |
| 연금술사 | 10회부터 5회마다 100코인 |

행운을 빌어요의 평균 반복 보상은 55코인이다. 아이콘 지급 단계 5회에는 코인이 없으며, 이후 장기 평균으로 뽑기 1회당 11코인의 보상이 추가된다. 실제 지급은 단계 수령 시에만 발생한다. 유형·특수에는 반복 보상이 없다.
