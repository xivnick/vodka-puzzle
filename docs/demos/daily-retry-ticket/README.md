# 다시 도전권 UI 예시

현재 검토용 예시는 [기존 사이트의 테스트 페이지](https://puzzle.xivnick.me/test/daily-sudoku/tickets/)다. 실제 `PuzzleLayout`, `NumberPad`, `PuzzleCompletion`, 데일리 스타일을 재사용하고 스트릭 옆에 도전권 링크만 추가한다. 구현은 `src/pages/test/daily-sudoku/tickets/index.astro`, `src/scripts/daily-retry-ticket-preview.js`, `src/styles/daily-retry-ticket-preview.css`에 있다. 아래 독립 정적 파일은 초기 시안으로, 현재 테스트 링크로 사용하지 않는다.

기존 데일리 스도쿠의 색상·너비·입력 구성을 따른 독립 정적 미리보기다. 로그인, DB, 클라우드 저장, 실제 완료 기록과 연결하지 않는다. 외부 스크립트와 폰트 없이 로컬 파일로도 열린다.

## 확인 흐름

1. `index.html`을 열면 10월 11일 문제와 다시 도전권 2장이 보인다.
2. 도전권 버튼 또는 ‘놓친 문제 풀기’를 누르면 보유량·획득 진행·10월 9일과 10월 10일 문제가 보인다.
3. 날짜를 선택하고 ‘1장 사용하고 시작’을 누르면 도전권 1장을 차감하고 과거 문제를 연다.
4. 오늘 문제로 돌아갔다가 보관함에서 과거 문제에 재입장해도 추가 차감하지 않는다. 입력과 메모도 유지한다.
5. 실제로 입력하거나 하단의 시연 전용 ‘완료 상태 보기’를 누르면 완료 화면을 확인할 수 있다. 완료는 행·열·3×3 구역의 규칙 준수로 판정한다.
6. 과거 문제 하나를 완성하면 기존 12회와 이어져 13회가 된다. 오늘 문제도 완성하면 14회가 된다. 양쪽 과거 문제와 오늘 문제를 모두 완성하면 15회가 된다.
7. ‘예시 처음부터’는 예시 상태를 초기화한다. 새로고침도 동일하다.

`?view=tickets`로 보관함이 열린 화면에 바로 진입할 수 있다.

## 예시 정책

- 하루 공백을 허용하는 현재 스트릭 규칙을 유지한다.
- 도전권은 날짜를 열 때 차감하고, 스트릭은 직접 완성한 뒤 반영한다.
- 데일리 누적 완료 30회마다 1장 지급, 최대 2장 보유 정책을 표시한다. 보유 한도에서는 지급 진행을 멈춘다. 초기 진행은 18/30으로 가정한다.
- 놓친 날짜는 최근 7일 중 미완료 문제다. 예시에서는 10월 9일·10월 10일이 해당한다.
- 한 번 연 문제는 재입장 비용과 완료 기한이 없다.
- 실제 지급·영구 저장·시간 경과·서버 처리는 구현하지 않는다.

## 로컬 미리보기

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/demos/daily-retry-ticket
```

브라우저에서 `http://127.0.0.1:8765/`를 연다. 정식 사이트 배포와 목록 등록은 포함하지 않는다.
