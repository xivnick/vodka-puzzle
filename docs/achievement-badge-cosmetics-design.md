# 업적 배지 색상·효과 설계

최종 정리: 2026-10-28. 레어 색 조합은 36색이 모두 1~2회 등장하는 수정안을 기준으로 확정한다. 별빛 반짝임은 일반 문제 전체 완료 특수 퀘스트의 전용 보상으로 추가한다.

## 기본 구조

업적을 달성하면 아이콘을 얻고, 획득한 색상과 효과로 이름 뒤 배지를 꾸민다. 업적 아이콘과 색상·효과의 획득을 구분한다. 일반 업적의 상세 목록은 별도로 구성하며, 확정한 전체 완료 특수 퀘스트 보상은 이 문서에 기록한다.

| 등급 | 구성 | 획득 | 에픽 효과 적용 |
|---|---|---|---|
| 커먼 | 기본 단색 36종 | 뽑기 | 불가 |
| 언커먼 | 자유로운 두 색 조합 또는 조합으로 만든 단색 | 커먼 3개 조합 전용 | 가능 |
| 레어 | 이름을 붙인 지정 색 조합 24종 | 뽑기 | 가능 |
| 에픽 | 흰색 광택 효과 5종 | 뽑기 | 언커먼·레어 색상 위에 적용 |

뽑기 대상은 커먼·레어·에픽이다. 언커먼은 뽑기에 넣지 않는다. 커먼 단색에 효과를 쓰려면 같은 색 3개를 조합해 언커먼 단색을 만든다.

## 언커먼 조합

- 커먼 3개를 재료로 사용한다.
- 서로 다른 색이 포함된 경우 재료 색 중 두 색으로 된 언커먼을 만든다. 자유 조합에서는 모든 두 색 조합을 허용한다.
- 같은 색 3개를 사용하면 해당 색의 언커먼 단색을 만든다.
- 단색의 외관은 커먼과 같지만 에픽 효과를 적용할 수 있다.
- 두 색의 2분할·그라데이션, 좌우·대각선 방향은 별도 아이템으로 나누지 않고 표현 옵션으로 취급한다.

현재 팔레트의 순서 없는 두 색 조합은 630종이고, 단색 36종을 더하면 이론상 666종이다. 방향·표현 방식은 이 수에 포함하지 않는다. 이는 가능한 조합 수이며 개별 이름 666개나 뽑기 항목 666개를 확정한 뜻은 아니다.

레어 지정 조합과 같은 두 색도 자유 조합의 허용 범위에 포함된다. 언커먼은 조합, 레어는 지정 조합을 뽑기로 얻는 구조다. 조합 결과를 레어로 자동 승급하는 규칙은 두지 않는 방향으로 정리한다.

## 뽑기 에픽 효과 5종

뽑기로 얻는 동작 효과는 다음 에픽 5종으로 묶는다. 색상을 바꾸지 않고 기존 색 위에 흰색의 투명도를 조절해 광택을 표현한다. 아이콘 자체의 이동·회전·변형은 사용하지 않는다. 별빛 반짝임은 아래 특수 퀘스트의 전용 보상으로 구분한다.

| 효과 | 표현 |
|---|---|
| 빛의 띠 | 대각선으로 빠르게 스치는 흰색 광택 |
| 포일 | 작은 면들이 드문드문 반짝인 뒤 기본 색으로 복귀 |
| 간섭광 | 곡선 무늬의 흰색 광택이 물결처럼 밝아짐 |
| 렌티큘러 | 부드러운 세로 결을 따라 짧고 선명하게 나타나는 광택 |
| 잔광 | 짧게 밝아진 후 천천히 기본 색으로 복귀 |

포일은 작은 아이콘에서 흰색 면적이 과해지지 않도록 일부 면만 반짝이게 한다. 현재 시안의 주기는 5.2초, 최대 불투명도는 0.85다. 외곽선 효과와 중심을 기준으로 회전하는 효과는 채택하지 않는다. 이전 실험 페이지는 비교 자료로만 보관한다.

## 전체 완료 특수 퀘스트: 별빛 반짝임

| 항목 | 내용 |
|---|---|
| 퀘스트 | 모든 일반 문제 완료 · 가칭 완전 정복 |
| 대상 | 해당 학기의 공개된 일반 문제 전체. 데일리는 제외한다. |
| 보상 | 별빛 반짝임 효과 |
| 획득 경로 | 전체 완료 특수 퀘스트 전용. 뽑기에는 포함하지 않는다. |
| 표현 | 아이콘 오른쪽 위의 작은 십자별이 회전하면서 밝아졌다 어두워진다. 아이콘 본체는 고정한다. |

별빛 반짝임은 초기 시안의 `sparkle` 효과를 기준으로 한다. 현재 시안은 2.8초 주기로 십자별의 투명도·크기와 회전 각도를 변화시킨다. [초기 시안](https://puzzle.xivnick.me/test/achievement-badges/)과 [소스](../src/pages/test/achievement-badges/index.astro)에 남아 있다.

특수 퀘스트에는 전체 대비 완료 개수와 미완료 문제 목록을 표시한다. 앞서 후보로 제안한 왕관 아이콘 대신 별빛 반짝임을 전체 완료 보상으로 채택한다. 현재는 설계 결정만 기록한 상태이며 실제 달성 판정·지급 기능은 구현하지 않았다.

## 표시·구현 기준

- 이름 뒤 실제 표시 크기는 18px이며 확대 시안과 함께 확인한다.
- 아이콘은 프로젝트 시안에서 사용하는 Tabler Icons의 모양을 유지한다. 아이콘 시안 12개를 업적 목록 확정으로 간주하지 않는다.
- SVG 그라데이션은 `gradientUnits="userSpaceOnUse"`와 24 × 24 좌표계를 사용한다. 수평·수직 경로가 있는 트로피 등이 누락되지 않도록 한다.
- 화면 밖과 비활성 탭에서는 효과를 멈추며, 동작 줄이기 설정과 일시정지를 지원한다.
- 테스트 페이지는 목록에 노출하지 않는다. 현재 페이지는 시각 비교용이며 실제 뽑기·재고·조합 기능은 연결하지 않았다.

### 닉네임 옆 아이콘의 공통 정렬

[NicknameBadge 컴포넌트](../src/components/NicknameBadge.astro)와 [정렬 스크립트](../src/scripts/nickname-badge-alignment.js)를 사용한다. 아이콘별 위치 보정이나 숫자 전용 크기·viewBox 예외를 두지 않는다.

- SVG의 `getBBox()`와 선 두께로 실제 그림 영역의 중심을 구한다. viewBox의 크기는 원본보다 줄이지 않고 중심만 이동하므로 기존 아이콘을 확대하지 않는다. 모든 아이콘은 같은 표시 영역에 원래 비율로 넣는다.
- 닉네임과 아이콘 기준점을 같은 글자 베이스라인에 놓는다.
- 실제 글꼴·크기·닉네임으로 `measureText()`의 `actualBoundingBoxAscent`와 `actualBoundingBoxDescent`를 읽는다. 글자 중심은 베이스라인에서 `(descent - ascent) / 2`이며, 이 위치에 아이콘 그림 중심을 맞춘다.
- 웹폰트가 로드되거나 글자 크기가 바뀌면 다시 계산한다. 같은 글꼴·문자열의 측정값은 재사용한다.

현재 적용 범위는 숫자 정렬 비교, 온도계·계산기·별 비교, 수식완성 후보 두 페이지의 이름 옆 아이콘이다. 기존 본 사이트의 배지나 효과 렌더러는 이 변경에 포함하지 않는다. [공통 정렬 시안](https://puzzle.xivnick.me/test/achievement-badges/number-alignment/)에서 12·14·16px, 한글·영문, 다른 글꼴과 여러 아이콘을 비교한다.

## 추가 결정 사항

- 뽑기 비용, 등급별 확률, 중복 획득 처리와 재료 수급량.
- 세 색이 모두 다를 때 결과 두 색을 사용자가 고를지 무작위로 정할지, 두 색만 섞인 재료의 처리 방식.
- 언커먼 조합의 이름·표기 방식. 채도나 재료 비율에 따른 추가 구분 여부도 미정이며, 현재 666종 계산에는 포함하지 않는다.
- 레어와 동일한 색 조합을 가진 언커먼의 소유·도감·중복 처리.
- 에픽 효과의 소유 단위와 적용·교체·소모 방식.
- 기본 지급색의 최종 선택.
- 별빛 반짝임의 등급, 적용 가능한 색상과 다른 효과와의 동시 사용 여부.
- 전체 완료 판정 이후 새 일반 문제가 추가될 때의 보상 유지·재달성 규칙.
