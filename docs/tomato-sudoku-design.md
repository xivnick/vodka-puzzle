# 토마토스 스도쿠 — 첫 플레이테스트

- ID: `261005_01`
- 상태: DB `test`, 공개 일시 없음
- 목표 난이도: 중간. 실제 플레이테스트 전이므로 확정 등급을 부여하지 않는다.
- 9×9 일반 스도쿠에 토마토 열 칸을 표시한다. 토마토 숫자 묶음은 `1 2 3 3 3 4 5 5 6 7`이다.
- 정답 배열과 비교하지 않고, 고정 숫자·일반 스도쿠·토마토 수량 규칙의 준수로 완료를 판정한다.

## 중심 추론

좌표는 1부터 센다. 토마토는 아홉 개의 3×3 상자에 하나씩 놓고 가운데 왼쪽 상자에만 하나를 추가한다. 박스별 개수는 위에서부터 `1·1·1 / 2·1·1 / 1·1·1`이다. 시작 숫자는 29개다.

초반에 6행의 8 후보는 r6c7과 r6c8뿐이다. r6c8은 토마토 칸이므로 8이 들어갈 수 없고, 따라서 일반 칸 r6c7이 8이다. 같은 방식으로 5열에서는 r3c5(토마토)를 제외해 r9c5가 8이고, 8열에서는 r6c8(토마토)을 제외해 r7c8이 8이다. 토마토를 제외하고 8의 위치를 찾는 것이 이 규칙의 주요 초반 추론이다.

반대 방향으로도 r6c8의 후보 `{5, 8}`에서 8을 지워 5를 확정할 수 있다. 토마토 조건을 쓰지 않는 단일 후보·숨은 단일 후보 풀이에서는 이 칸이 확정되지 않는다.

시작 단서에서 토마토 중 3의 후보 위치는 r1c2, r1c9, r5c6, r8c8 네 곳이다. 1행의 두 칸에는 동시에 3을 넣을 수 없으므로 r5c6과 r8c8은 3이다. 토마토 중 2의 후보는 r1c9뿐이므로 그 칸은 2, 따라서 r1c2는 3이다. 이후에는 상자와 행·열의 후보 위치를 연결하는 소거(locked candidates)를 사용하며, 추측이나 더 높은 단계의 기법 없이 진행된다.

## 화면과 저장

아이콘은 칸 전체에 옅은 회색 배경으로 표시한다. 보드 위에는 숫자 묶음 `1 2 3 3 3 4 5 5 6 7`만 일반 텍스트로 고정 표시한다. 채운 칸 수, 숫자별 사용량, 취소선은 표시하지 않는다. 규정 수량 초과 및 토마토의 8·9 입력은 기존 규칙 위반 표시를 따른다.

기기 저장에는 보드 서명을 포함해 이후 단서 변경 시 이전 시안의 입력이 섞이지 않게 한다. 목록·완료 기록·클라우드는 기존 DB 공개 상태 제어를 따른다.

## 확인 범위와 후속 조정

현재 배치에 일반 스도쿠와 토마토 수량 규칙을 적용한 탐색에서 해가 정확히 하나임을 확인했다. 토마토 규칙 없이 시작 숫자와 일반 스도쿠만 적용하면 해가 둘 이상이다.

후보 소거 비교에서 일반 스도쿠의 단일 후보·숨은 단일 후보만으로는 시작 숫자 외에 7칸이 채워진다. 여기에 8·9 제외만 적용하면 r6c8의 5를 포함해 16칸이 채워진다. 토마토 수량 규칙까지 적용하면 21칸이 채워지고 31칸이 남는다. 상자와 행·열의 후보 위치를 연결하는 소거를 추가하면 모든 칸이 채워진다. 이는 기계적인 논리 진행 비교이며 실제 체감 난이도는 아직 플레이테스트하지 않았다.

플레이테스트에서는 r6c8의 8 제외를 먼저 발견하는지, 3의 수량 추론과 후보 위치 연결 단계에서 어디서 막히는지 기록한다.
