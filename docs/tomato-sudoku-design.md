# 토마토스 스도쿠 — 첫 플레이테스트

- ID: `261005_01`
- 상태: DB `test`, 공개 일시 없음
- 목표 난이도: 중간. 실제 플레이테스트 전이므로 확정 등급을 부여하지 않는다.
- 9×9 일반 스도쿠에 토마토 열 칸을 표시한다. 토마토 숫자 묶음은 `1 2 3 3 3 4 5 5 6 7`이다.
- 정답 배열과 비교하지 않고, 고정 숫자·일반 스도쿠·토마토 수량 규칙의 준수로 완료를 판정한다.

## 중심 추론

아래 좌표는 1부터 센다. 시작 단서만으로 토마토 중 3의 후보 위치는 r1c1, r1c2, r4c9, r8c8 네 곳이다. 앞의 두 칸은 같은 행이므로 동시에 3일 수 없다. 따라서 세 개의 3을 배치하려면 r4c9와 r8c8은 모두 3이어야 한다. 일반 단서만 적용한 두 칸의 초기 후보는 각각 {1,2,3,5,7}, {3,5}로, 단순한 단일 후보로 주어지지 않는다.

토마토 중 6이 가능한 위치는 처음부터 r9c6 하나다. 수량으로 숫자를 확보하는 쉬운 진입점과 3의 위치 관계를 결합하는 중심 장면을 함께 둔다. 이외에는 8·9 제외와 한 번뿐인 숫자의 전역 후보 제거를 활용한다.

## 화면과 저장

아이콘은 칸 전체에 옅은 회색 배경으로 표시한다. 보드 위에는 숫자 묶음 `1 2 3 3 3 4 5 5 6 7`만 일반 텍스트로 고정 표시한다. 채운 칸 수, 숫자별 사용량, 취소선은 표시하지 않는다. 규정 수량 초과 및 토마토의 8·9 입력은 기존 규칙 위반 표시를 따른다.

기기 저장에는 보드 서명을 포함해 이후 단서 변경 시 이전 시안의 입력이 섞이지 않게 한다. 목록·완료 기록·클라우드는 기존 DB 공개 상태 제어를 따른다.

## 확인 범위와 후속 조정

초기 후보 관계, 규칙 위반 처리, 입력·메모·지우기·고정 숫자 보호·기기 저장 코드와 모바일 레이아웃을 확인했다. 정답 존재 여부·유일성 검사 및 전체 풀이 탐색은 수행하지 않았다.

플레이테스트에서는 3 수량 추론의 발견 여부, 이후 막히는 위치, 일반 스도쿠만으로 우회되는 정도를 기록한다. 이를 근거로 단서를 조정하며, 아직 중간 난이도나 추측 없는 완주를 검증한 퍼즐로 표현하지 않는다.
