# 업적 서버 작업 현황

작업일: 2026-11-05.

## 이번 작업

- 신규 private 테이블 12개와 내부 거래 함수 4개, 미완료 거래 커밋 방지 함수·제약 트리거를 구현한다.
- 계정 잠금, 요청 UUID 재전송, 코인·재고와 원장 동시 갱신, 영구 아이템 소유 제약, 미션 중복 수령 제약을 준비한다.
- 확정 아이템 정의 87개와 비활성 뽑기 설정 초안을 넣는다. 가격과 반복 보상 미정 값은 운영 값으로 넣지 않는다.
- 현재 장착만 보관한다. 장착 이력·기능 누적 카운터·별도 업적 달성 기록은 만들지 않는다.
- 운영 계정의 지갑·재고·수령 기록은 생성하지 않는다. 공개 API·기존 완료 API·프런트엔드는 변경하지 않는다.

## 운영 적용·확인

- `20261105_cosmetic_foundation.sql`을 운영 DB에 적용했다. 기능 스위치는 false이고 가격 NULL의 draft 설정만 존재한다.
- 적용 전후 기존 public/private 함수·테이블 37개의 정의·권한을 비교했다. 기존 객체는 동일하며 공개 RPC는 추가하지 않았다.
- 운영 사용자 지갑·재고·거래·수령 기록은 모두 0건이다. 아이템 정의 87개만 등록했다.
- 마이그레이션 전체를 롤백하는 사전 검증과 적용 후 롤백 검증을 통과했다. 비활성 요청, 재전송, 잘못된 요청 ID 재사용, 잔액·재료 부족, 영구 아이템, 중복 수령, 원장 일치, 미완료 커밋 거절, 권한, 계정 삭제를 확인했다.
- 별도 임시 계정으로 내부 거래 함수에 100코인 동시 차감 두 건을 실행했다. 한 건만 성공하고 나머지는 잔액 부족으로 롤백됐다. 잔액·원장 합계가 일치했고 임시 계정과 거래는 삭제했다. 공개 RPC와 화면의 동시 요청 검증은 후속 단계다.
- 기존 완료 API나 실제 화면은 변경하지 않았다.

## 남은 구현

1. 업적 규칙과 유형·특수 문제 ID 연결, 원본 기록 기반 진행도·수령 조건 조회.
2. 일반 퍼스트 블러드의 최초 완료자 고정 및 기존 기록 처리.
3. 장착 API와 소유·종류·효과 적용 조건·버전 충돌 검증.
4. 서버 난수 뽑기·커먼 3개 조합·중복 코인 환급 API.
5. 업적·데일리 수령 API와 기존 타임머신 티켓 보상 연결.
6. 완료 API의 새 달성 응답·토스트, 실제 화면과 랭킹 표시 연결.
7. 동시 요청·한국 자정·응답 역전·타임머신 복원 등 통합 검증 후 활성화.

## 결정할 항목

- 반복 업적 코인 보상량.
- 뽑기 가격.
- 데일리 챔피언 티켓 수량.
- 기존 기록 소급, 미수령 전체 완료 달성 후 문제 추가 시 처리, 데일리 수령 기한 정책.

공개 RPC 구현 시에도 기능은 비활성으로 유지할 수 있다. 완료 API와 운영 화면 연결은 기존 동작에 영향을 주는 별도 단계로 진행한다.
