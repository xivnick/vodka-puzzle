# 폭탄 스도쿠 중간 난이도 시안

테스트 경로: `/test/bomb-sudoku/261001/`

폭탄 위치 9개와 일반 숫자 25개를 공개한다. 폭탄 값은 모두 플레이어가 입력한다. 기존 화면, 규칙, 조작 방법, 완료 판정 방식을 유지하며 목록과 클라우드 저장에는 연결하지 않는다.

## 출제 과정

스도쿠 완성 패턴의 행·열·숫자를 섞어 바탕을 구성했다. 폭탄 이웃의 비교 조건을 포함해 값을 배정할 수 있는 구성을 고른 뒤 숫자 단서를 줄였다. 단서 삭제는 개수를 최소화하는 것이 아니라 아래 네 장면이 허용한 추리로 이어지는 것을 기준으로 조정했다. 마지막으로 일반 숫자 단서 하나를 더 제거해 폭탄 값이 이웃 숫자를 결정하는 장면을 남겼다.

## 의도한 장면

이 절은 출제 검토용이며 일부 풀이 정보를 포함한다.

- 4행 5열과 7열의 후보가 각각 `{3,8}`이다. 6열의 폭탄 값은 몰라도 왼쪽은 3, 오른쪽은 8로 정해진다.
- 기본 스도쿠로 얻은 이웃 숫자 4·5, 5·6, 3·4 사이에서 각각 4.5, 5.5, 3.5 폭탄을 결정한다.
- 이미 사용한 폭탄 값을 다른 폭탄 후보에서 제외한다. 두세 후보에서 하나가 남는 과정이 이어진다.
- 8행 7열의 폭탄이 2.5로 정해지면 바로 왼쪽인 6열의 후보 `{2,4}`는 2가 된다. 이후 기본 스도쿠로 마무리한다.

## 난이도 기준과 점검

허용한 일반 스도쿠 추리는 기존 숫자 제외와 후보 하나, 들어갈 자리 하나, 두 칸의 같은 두 후보 묶음이다. 폭탄 추리는 좌우 순서 비교, 이웃 숫자로 값의 범위 좁히기, 사용한 값 제외, 값이 들어갈 자리 하나, 두 폭탄의 후보 묶음, 폭탄 값으로 이웃 후보 좁히기로 제한한다.

`python3 scripts/grade-bomb-sudoku.py`는 이 추리들을 순서대로 적용한다. 기본 스도쿠 추리가 멈춘 뒤에만 폭탄 비교를 적용하므로 기록된 폭탄 추리는 허용한 기본 추리의 막힘을 해소한다. 분기, 가정, 역추적, 해 개수 탐색, 정답 대조를 사용하지 않는다. 완성 답안을 저장하지 않는다.

현재 시안은 위 추리만으로 모든 칸의 후보가 하나가 된다. 일반 스도쿠에서는 서로 다른 두 후보 묶음 2개를 사용하며, 이로 인한 후보 제거가 4건이다. 폭탄 양옆의 `{3,8}` 순서 결정, 연속된 이웃으로 폭탄 값 결정, 사용한 값으로 폭탄 결정, 폭탄 값으로 이웃 결정이 모두 나타난다. 폭탄 비교를 제외하면 일반 숫자 23칸이 미정으로 남는다.

중간 난이도는 위 추리 범위와 연결을 기준으로 한 출제 목표다. 실제 플레이 시간과 체감 난이도는 아직 평가하지 않았다.
