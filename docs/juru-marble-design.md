# 주루마블 스도쿠 제작 기준

첫 문제는 `261101_01`이며, 일반 목록에 공개하지 않는 DB 테스트 상태로 제공한다.

## 규칙

각 행·열·3×3 상자에는 1~9가 한 번씩 들어간다. 잔은 맨 윗줄 가운데에서 출발해 현재 칸의 숫자만큼 32칸 경로를 시계 방향으로 전진한다. 출발 칸에 정확히 도착해 한 바퀴를 끝내야 한다.

출발 칸과 중간 정차 칸은 서로 같은 행·열·상자에 있을 수 없고 숫자도 모두 달라야 한다. 귀환한 출발 칸은 다시 세지 않는다. 통과한 칸에는 정차 제약을 적용하지 않는다.

## 의도한 풀이 흐름

1. 출발 칸은 빈칸이다. 최초 후보가 두 개 이상인 상태에서 위쪽 가운데 상자의 숨은 싱글로 결정된다.
2. 일반 스도쿠의 싱글·숨은 싱글·영역과 줄의 후보 제한·네이키드 페어를 먼저 적용한다.
3. 일반 스도쿠 풀이가 막히면 현재 알려진 정차 경로의 마지막 칸에서 이동 후보를 검토한다.
4. 바로 다음 정차는 가능하지만 뒤쪽 이동에서 정차 숫자 또는 위치가 겹치는 후보를 제거한다.
5. 경로로 결정한 숫자를 다시 일반 스도쿠에 사용한다. 두 방식이 여러 차례 교차한다.
6. 마지막에는 남은 거리와 이미 사용한 숫자를 이용해 귀환을 결정한다.

## 첫 문제의 검토 결과

- 주어진 숫자 22개, 출발 칸은 빈칸이다.
- 일반 스도쿠 조건만 만족하는 서로 다른 완성 배치를 두 개 확보했다. 경로 없이 최종 답을 결정할 수 없다.
- 일반 스도쿠 풀이와 경로 후보 제거만으로 전체 칸을 채우는 논리 기록을 확보했다.
- 해당 기록에는 경로 후보 제거 9건이 있다. 이 중 3건은 현재 이동만 확인해서는 제거되지 않고 뒤쪽 이동을 봐야 한다.
- 앞보기는 현재 이동을 포함해 최대 3회로 제한했다. 가정한 숫자로 스도쿠 전체를 탐색하거나 모든 정차 패턴을 정답처럼 대조하지 않는다.
- 경로 추론 사이에 일반 스도쿠의 숫자 확정이 반복된다.

제작 시 경로 규칙을 제거해도 다른 완성 배치가 남는지는 사용자 요구사항으로 검토한다. 완성 여부를 판정하는 클라이언트는 저장된 해답과 비교하지 않고, 주어진 숫자와 일반 스도쿠·정차·정확한 귀환 조건을 직접 확인한다.

## 재현과 산출물

```sh
node scripts/create-juru-marble.mjs work/juru-marble-design-20261101 261101
```

생성기는 의도한 시작과 교차 추론, 뒤쪽 모순을 포함한 문제만 보존한다. 생성 실패 시 오류로 종료한다.

풀이 숫자와 상세 논리 기록은 지정한 로컬 작업 디렉터리에만 저장한다. `src/data/juru-marble.js`에는 공개 가능한 주어진 숫자만 포함한다. 작성 도구와 정답은 클라이언트에 포함하지 않는다.

## 화면과 저장

기존 테스트 시안 `/test/juru-marble/`은 빈 입력판으로 유지한다. 실제 문제는 `/261101_01/`에서 제공한다. 입력 숫자는 가운데 정렬하고 잔은 회색 배경으로 표시한다. 숫자를 수정하면 정차 잔 전체를 재계산하며, 메모에는 경로 표시를 생성하지 않는다.

실제 문제의 숫자와 메모는 기기에만 저장한다. 완료 기록과 클라우드 저장은 연결하지 않으며, 공개 상태와 공개 일시는 변경하지 않는다.

## 교차 풀이를 강화한 두 번째 시안

첫 시안은 일반 스도쿠 추론이 경로 추론 사이에 나타났지만, 경로 전체가 결정되는 시점에 빈칸이 32개 남았다. 따라서 실제 경험은 경로를 먼저 해결하고 나머지 스도쿠를 채우는 쪽에 가까웠다. 단순히 두 기법이 교대로 사용되는지만 보는 제작 기준은 충분하지 않았다.

두 번째 시안은 `/261101_02/`에서 별도 DB 테스트 문제로 제공한다. 첫 문제와 진행 저장은 변경하지 않는다.

`--interleaved` 제작 모드는 다음 조건을 추가한다.

- 서로 다른 정차 칸 세 곳 이상에서 경로 후보를 제거한다.
- 출발 외의 실제 정차 숫자 중 하나 이상은 해당 칸에 경로 후보 제거를 적용하지 않고 일반 스도쿠로 결정한다. 이 결정은 첫 경로 추론 이후에 나타나야 한다.
- 경로 추론 사이에 일반 스도쿠 숫자 확정이 네 번 이상인 구간이 세 개 이상 있어야 한다. 한 구간이 20칸을 넘지 않게 한다.
- 일반 스도쿠의 후보 제한까지 반영한 정차 패턴이 하나로 정해지는 시점에는 빈칸이 20개 이하여야 한다.
- 입력값으로 경로 전체가 이어지는 시점에는 빈칸이 12개 이하여야 한다.
- 첫 시안의 숨은 싱글 출발, 뒤쪽 모순을 통한 후보 제거, 일반 스도쿠만으로 남는 복수 완성 배치 조건도 유지한다.

두 번째 시안에는 단서 23개가 있다. 검토한 풀이에서는 경로 후보 제거 사이에 일반 스도쿠로 13칸·16칸·14칸을 확정하는 구간이 나타난다. 가능한 정차 패턴이 하나로 좁혀질 때 빈칸은 17개이며, 실제 입력으로 경로 전체가 이어질 때는 8개다. 처음부터 경로 패턴을 하나로 고를 수 있는 후보는 제외했다.

정차 패턴의 수는 제작 품질을 평가하는 별도 지표다. 풀이 검토기는 이 패턴 목록을 정답으로 사용하지 않고 기존의 제한된 앞보기만 사용한다.

```sh
node scripts/create-juru-marble.mjs work/juru-marble-design-20261101-balanced 261102 --interleaved
```
