Rat Run 1 규칙
기본적인 6×6 스도쿠 규칙을 따릅니다. 각 행, 열, 3×2 박스에는 1~6이 한 번씩 들어갑니다.
쥐는 미로 벽을 뚫지 않고 컵케이크까지 이동합니다. 경로는 칸 중심을 잇고, 지나간 칸을 다시 방문하거나 다른 경로와 교차할 수 없습니다.
보통은 상하좌우로 이동하지만, 2×2 공간이 벽 없이 비어 있으면 대각선 이동도 가능합니다.
경로 위의 인접한 두 칸의 합은 모두 소수여야 합니다. 각 3×2 박스마다 경로 위 숫자들의 합도 소수여야 합니다.
