# Achievement badge preview icons

Tabler Icons v3.40.0, outline, MIT license in `LICENSE`.
Source: https://github.com/tabler/tabler-icons/tree/v3.40.0/icons/outline

`trophy`, `medal`, `flame`, `puzzle`, `star`, `plant`, `bolt`, `moon` reuse the earlier achievement demo icons. `diamond`, `crown`, `rosette`, `flower` are downloaded from the same version. Original SVG shapes remain unchanged; the preview uses CSS masks to apply color finishes.

Challenge preview adds `calendar-check`, `history`, `temperature`, `bomb`, `wind`, `building-skyscraper`, `calculator`, `scale`, `snowflake`, `ripple`, `pentagon`, `fence`, `navigation`, and `archery-arrow` from the same pinned v3.40.0 outline set, with their original SVG geometry. Its tomato uses the project's existing IconPark asset at `/icons/tomato.svg`; attribution is in `/icons/tomato-LICENSE.md`.

Math badge alternatives add `sum`, `square-root`, `math`, `math-symbols`, `equal`, and `abacus` from the same pinned Tabler Icons v3.40.0 outline set. SVG geometry is unchanged.

Additional formula achievement candidates use `brain`, `bulb`, `pencil`, `writing`, `school`, `flask`, `atom`, `number-123`, `function`, and `variable` from the same pinned Tabler Icons v3.40.0 outline set, unchanged.

Difficulty mission candidates add `cherry` and `skull` from the same pinned Tabler Icons v3.40.0 outline set, unchanged; `brain` reuses the existing candidate asset.

First-blood reward candidates add `sword` and `swords` from the same pinned Tabler Icons v3.40.0 outline set, unchanged, and reuse `crown`.

Basic mission preview adds `leaf` from the same pinned Tabler Icons v3.40.0 outline set, unchanged, and reuses `puzzle` and `flame`.

Spiral Galaxies mission candidates add `galaxy`, `spiral`, `universe`, and `planet` from the same pinned Tabler Icons v3.40.0 outline set, unchanged.

Account setting buttons use the original `palette` from the same pinned Tabler Icons v3.40.0 outline set (MIT), and reuse `pencil`.

Inline nickname editing uses the original `check` from the same pinned Tabler Icons v3.40.0 outline set (MIT).

Customization navigation uses the original `chevron-right` from the same pinned Tabler Icons v3.40.0 outline set (MIT).

Feature introduction achievements add the original `hanger` and `dice-5` from Tabler Icons v3.40.0 outline (MIT), and reuse the existing `flask`. SVG geometry is unchanged.

The Lucky Hand achievement replaces its dice with the original `clover` from Tabler Icons v3.40.0 outline (MIT). Existing dice owners and equipped previews migrate to `clover`.

Time Traveler candidates reuse `history` and add `hourglass`, `clock-bolt`, `calendar-time`, and `rocket` from the same pinned Tabler Icons v3.40.0 outline set (MIT), without geometry changes.

Sudoku Raid achievement candidates add `shield-checkered`, `axe`, `building-castle`, `chess-knight`, and `flag-3` from the same pinned Tabler Icons v3.40.0 outline set (MIT). SVG files are downloaded unchanged from the official repository; the comparison page links to each original.

Sudoku-focused raid candidates add `grid-pattern`, `grid-3x3`, `grid-4x4`, `border-inner`, and `number-9` from the same pinned Tabler Icons v3.40.0 outline set (MIT), without geometry changes.

Pepero Sudoku achievement candidates add `number-11`, `baguette`, `candy`, and `cookie` from the same pinned Tabler Icons v3.40.0 outline set (MIT). Original SVG geometry is unchanged. These are preview candidates only.
